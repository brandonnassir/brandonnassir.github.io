Methodology

For each embedding type, we identify the k=10 nearest neighbors of each problem in the high-dimensional embedding space using cosine similarity. We then measure neighborhood label homogeneity - the proportion of neighbors sharing the same attribute value (difficulty, domain, skill, or problem type). Statistical significance is established via 1,000 permutation tests, comparing observed homogeneity against a randomized null distribution.

Homogeneity

% of neighbors with same label. Higher = stronger clustering.

Effect Size

Number of standard deviations observed homogeneity beats a random baseline. Cohen's d: small (0.2), medium (0.5), large (0.8).

Significance

−log₁₀(p) turns tiny probabilities into an easy-to-read score where a larger value (a taller bar) means stronger evidence that the result is not due to chance.

Lift

How many times better than random is the homogeneity ex. 2x => twice as clustered as random.
